## 關鍵發現

1. **A5 真機驗證成立**(Claude Code 2.1.322,本 session):跑 `claude plugin test` 觸發一條本 session 未觸發過的 `mod-test-kit-limits`。畫面上只有一般 hook 的一則提示；`<base>/trips/<session>.json` 有記到這一條(mod 比對到了),`<base>/hints/claude-<session>.json` 的 toolUseId 就是那次呼叫。mod 因為 hook 已經提示過，沒有再印。改版號那次 `sed` 一次命中 5 條，也只出現一份。
2. **npm 發佈後約 10 分鐘才看得到**:release run 日誌有 `+ flightwake@0.19.0`,前一行是 `Your package is being processed and may take a few minutes to become available.`;`https://registry.npmjs.org/flightwake/0.19.0` 在 01:41 到約 01:51(UTC)之間一直回 404。之後發版驗證要等，不要以為失敗而重發。
3. **`--version` 的根因**:`bin/cli.mjs` 把第一個不是 `-` 開頭的參數當指令，找不到就預設 `init`,所以 `--version` 會直接安裝。同一個原因下，打錯的旗標(`--privat`)也會照裝，只是少了那個選項。修法：`--version` / `-v` / `version` 只印版號；install / uninstall / doctor 遇到不認得的旗標，在讀寫之前就拒絕。只帶旗標不帶指令仍照舊跑 init(setup 審查要求保留，見 `docs/plans/setup.review-astra.md` 第 1 點)。
4. **影片製作的工具鏈**(檔案在 Kai 桌面 `~/Desktop/計畫案/影片製作/`,不進 repo):`build_v3.py` 產橫式、`build_v4.py` 產直式(1080×1920:品牌列、標題、1080 方框、字幕),`remotion/` 是動畫元件；改素材後重跑腳本即可。片尾動畫 E1 用 Flow 生成，花 15 點(B2 累計 78 點)。配樂用 theme A。細節與 Kai 的定案在 `docs/plans/demo-video.md`。
