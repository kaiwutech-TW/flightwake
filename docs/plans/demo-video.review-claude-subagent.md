- **輕微:解析度只有 560px 高**,低於 720p 輸出。檔名有 preview,如果有原尺寸的檔案,應該用原檔。

### H1

- 輕微:手的動作太多。首幀兩手都在鍵盤上;尾幀一手抵臉頰,另一手看起來插進口袋(約 x 700–760、y 420–470),等於兩隻手臂同時在動。

### H2

- 輕微:尾幀露出的不只有帽子和護目鏡,雙手和一部分臉也露在洞外,和規格不同。

### H3

- 輕微:尾幀儀表板沒有「全暗」。上方一排小燈(綠、綠、紅,約 x 505–540、y 232–246)和紅色撥鈕(約 x 497、y 373)還亮著。

### 沒有驗證的部分

- Flow 遇到 1.95:1 的圖是裁切還是補黑邊。
- 是否有原尺寸的檔案。
- 手指數:這個解析度下大多看起來是 4 指(Q 版常見畫法),我沒辦法確定是否有畸形。
- 「模型會怎麼變形」都是根據首尾幀差異的推論,沒有實際生成過。
- 我沒讀 docs 原文,只依你給的規格摘要;也不知道青綠夾克那位有沒有其他設定。

### 考慮過但不採用的判斷

- **沒推近或拉遠不列嚴重:** 影片不會因此出錯,後製縮放更省點數、也更好控制。
- **H2 不是低角度不列嚴重:** 低角度看不到洞裡,摔進洞的笑點反而不成立,而且首尾幀一致,不會變形。
- **H4 和 H1 同機位不列違規:** 兩格不相鄰,看得出是刻意前後呼應。
- **問號、「!」和便利貼上的橫線不算文字。**
- **背景物件跳動不列:** 差異圖證實沒有。
